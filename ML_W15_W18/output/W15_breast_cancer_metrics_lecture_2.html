混淆矩陣、ROC 與 PR 曲線

第零節 · 費米暖身

費米估算：先用數量級逼近答案

面對一個陌生的大問題，別急著查精確數字。費米估算的精神是：先用常識把問題拆成幾個可估的小量，相乘得到一個「數量級正確」的快速答案。它的真正價值不在那個數字，而在拆解的過程會逼你看見：要回答這題，我到底需要懂哪些東西。本篇所有的知識點，都是被下面這道題「逼」出來的。

費米 Q
你訓練的乳癌診斷模型 accuracy = 0.95，部署到台中某醫院，一天會錯判幾位患者？

用「見 → 識 → 謀 → 斷」四步拆解

這是把大問題切成可估小量的鷹架：見（盤點已知的量）、識（辨認關鍵的陷阱與機制）、謀（決定怎麼算、怎麼呈現）、斷（落地成行動）。

見 · 盤點已知量 識 · 辨認機制與陷阱 謀 · 決定算法與呈現 斷 · 落地行動
步驟拆解的問題數量級估算
見一天有多少人做乳房攝影？約 80–120 人／日（取 100）
見其中真有問題（陽性）的比例？約 1–3%（基準率，取 2%）
識95% accuracy 但盛行率只有 2%，意味什麼？accuracy 騙人，要看 recall
識若 recall=0.80、precision=0.30，每天漏失幾位？≈ 0.4 位（每 2.5 天漏 1 位）
謀要怎麼讓主管看到這個衝突？畫混淆矩陣 + PR 曲線，不畫單一 accuracy
斷模型能不能上線？門檻訂在哪？依 PR 曲線選召回門檻，而非看 accuracy
30 秒得到的答案 100 人 × 2% = 2 位真患者。recall 0.80 → 抓到 1.6 位、漏失約 0.4 位／日；precision 0.30 → 判陽性約 5.3 位，其中 誤警約 3.7 位／日。一個 accuracy「0.96」的模型，每 2.5 天就漏掉一位真正的乳癌患者。這就是費米估算：數字未必精準，但數量級與衝突已經浮現。

估算暴露了哪些知識缺口？這就是本篇的學習地圖

上面每一個「識／謀／斷」的格子，背後都藏著一個你必須先弄懂的概念。把它們一一接到後面的章節——這就是「問題導向」的學習：不是先學完理論才解題，而是讓題目決定你該學什麼。

帶走 費米估算先給你一個數量級正確的答案，更重要的是它暴露了你的知識缺口。接下來六節，就是把這些缺口一個個用費曼學習法講透——講到你能教給沒寫過程式的廠長聽。
第一節

開場謎題：0.95 的假象

假設台中某醫院一天有 100 人做乳房攝影，其中真正有問題的約 2 人（盛行率 2%，這是篩檢族群的真實基準率）。你訓練的模型 accuracy = 0.95，聽起來很安全。但 accuracy 在這裡會騙人。

原因是：一個「對所有人都判沒事」的懶惰模型，光是把 98 個健康人猜對，accuracy 就有 0.98 了——比你的模型還高，卻一個病人都救不到。當一類遠多於另一類，accuracy 會被多數類別灌滿，把真正重要的「漏診」藏起來。

關鍵轉折 accuracy 回答「整體猜對幾成」，但醫院真正怕的是「漏掉幾位真患者」。這兩個問題的答案，可以天差地遠。要看清後者，得先把模型的判定攤成一張 2×2 的表。
帶走 在低盛行率任務裡，高 accuracy 只是「把大量健康人猜對」的獎勵，它對病人的死活幾乎沒有發言權。
第二節

混淆矩陣：一個母體 × 一個模型

混淆矩陣是「一個母體」和「一個模型」的交叉。母體依真實狀況分兩群（真患者 / 健康人）；模型依預測結果分兩類（判陽性 P / 判陰性 N）。兩者交叉，得到四格。

依你的偏好，這裡把真實放在行（直向）、預測放在列（橫向）。於是：

預測（列·橫） 真實狀況（行·直）
真患者 健康人
判陽性 P
TP 真陽
1.6
FP 誤警
3.7
判陰性 N
FN 漏失
0.4
TN 真陰
94.3

四格各自的意思：TP 真患者被正確抓到；FN 真患者卻被放走（漏失，最致命）；FP 健康人被誤判召回（誤警，造成焦慮與負荷）；TN 健康人被正確排除。

三個指標，在矩陣裡走不同的路

之後所有的曲線，都是從這四格用不同方式組合出來的。先記住三條路徑——這是理解 ROC 與 PR 差異的鑰匙：

recall = TP / (TP + FN) → 沿「真患者」這一行（直）算
precision = TP / (TP + FP) → 沿「判陽性」這一列（橫）算
FPR = FP / (FP + TN) → 沿「健康人」這一行（直）算
幾何直覺 TN 坐在矩陣的右下角。recall 走真患者那條直行、precision 走判陽性那條橫列——兩條路都繞開了右下角。只有 FPR 走健康人那條直行，正好踩進 TN。這個位置差異，是後面所有故事的根源。
帶走 混淆矩陣是「真實（行）× 預測（列）」的 2×2；每個評估指標，本質上就是在這張表裡選哪幾格、沿哪個方向相除。
第三節

閾值：那條看不見的切割線

模型對每位病人輸出的不是「有癌／沒癌」，而是一個 0～1 的機率（例如 0.87，代表「我覺得有 87% 像有問題」）。但醫院最終要做二選一的決定。閾值就是那條切割線——規定「機率 ≥ 閾值」才判陽性。

真患者的機率通常偏高、健康人偏低，但兩座「機率山」會部分重疊。閾值就是插在重疊區的那把刀。拖動下面的閾值，看兩座山如何被切開：

0.50
真患者分布 健康人分布

切割線右側 = 判陽性。線往左 = 閾值降低 = 越寬鬆 = 抓到更多真患者，但也掃進更多健康人。同一把刀，同時切兩座山——這就是為什麼兩群人的命運被綁在一起。

兩個極端：閾值不是越低越「抓得到」

閾值的方向很容易記反，務必釐清——規則是「機率 ≥ 閾值才判陽性」：

閾值 = 0（最寬鬆）→ 人人機率都 ≥ 0 → 全判陽性 → TPR=1, FPR=1 → 落在 (1, 1)
閾值 = 1（最嚴格）→ 幾乎沒人達標 → 全判陰性 → TPR=0, FPR=0 → 落在 (0, 0)
常見誤解 一個「對誰都不喊陽性」的模型（閾值≈1），既不會錯抓任何健康人，也抓不到任何真患者，所以必然待在原點 (0,0)。閾值越高 → 越嚴格 → 點越靠近左下角。
帶走 閾值是唯一一個你部署後還能轉的旋鈕。它不改變模型能力，只決定你在曲線上「站哪一點」。
第四節

ROC 曲線：兩群人的命中率

ROC 把母體的兩群人，各算一個「被判陽性的機率」，配成一對座標：

Y 軸　TPR = recall = TP/(TP+FN)　→ 真患者中被抓到的比例
X 軸　FPR = FP/(FP+TN)　　　　 → 健康人中被誤警的比例

注意兩者都是條件機率，但針對不同群體：TPR 的分母只看真患者，FPR 的分母只看健康人。它們各自描述一群人的命運——在矩陣裡，兩者都沿直行（真實分群）計算。

為什麼「亂猜」是一條對角線？

若模型毫無鑑別力、純粹擲骰子決定「隨機把比例 p 的人判陽性」，因為它不看任何資訊，真患者被挑中的機率，跟健康人被挑中的機率完全一樣，都是 p。於是 TPR = p、FPR = p，兩者恆等 → 點落在 y = x 對角線上。把所有 p 掃一遍，就連成從 (0,0) 到 (1,1) 的對角線。

及格底線 對角線代表「零鑑別力」。一個有用的模型，必須對真患者比對健康人更容易喊陽性（TPR > FPR），點才會跑到對角線左上方。曲線離對角線越遠 → 模型越會「分人」。
帶走 ROC 曲線上的每一點，是「同一個閾值」同時套到兩群人身上算出的 (FPR, TPR)。寬嚴標準對兩群一致，這是 ROC 的靈魂。
第五節

PR 曲線：繞開 TN 的路徑

PR 曲線換了一對搭檔：

Y 軸　precision = TP/(TP+FP)　→ 判陽性裡，多少是真的
X 軸　recall = TP/(TP+FN)　　 → 真患者裡，抓到多少

關鍵的不對稱在這裡：recall 沿真患者那條「行（直）」算，precision 沿判陽性那條「列（橫）」算。兩個指標一個走直、一個走橫——而它們在矩陣裡的路徑，都繞開了右下角的 TN。

對照：ROC 的 FPR = FP/(FP+TN) 走「健康人」那條直行，分母含 TN；PR 的兩個指標完全不碰 TN。當健康人有 98 個、TN 巨大時，這個差異會徹底改變兩條曲線的「臉色」。

為什麼 PR 的基準線不是對角線？

PR 裡「亂猜」的 precision = 判陽性中真患者的比例。亂猜時，你挑中的人裡真患者的比例，就等於母體裡真患者的比例——也就是盛行率（本例 0.02）。所以 PR 的基準線是一條壓在 0.02 的水平線，而且會隨盛行率上下移動；不像 ROC 的對角線永遠固定。

帶走 PR 取一條「行」（recall）配一條「列」（precision），兩條路徑都避開 TN，所以在 TN 海量的低盛行率任務裡不被稀釋。

同一批誤警，兩條曲線各說各話

把閾值放寬時請對照 FPR 與 precision 這兩個「誤判」指標：

  • FPR 只爬到約 0.04——被 98 個健康人的分母稀釋，看起來無害。
  • precision 同一時刻已掉到 0.33——誤警直接打在「判陽性的可信度」上，藏不住。
何時信誰 資料平衡、且同等在乎兩類錯誤 → ROC 適用（門檻穩定、跨資料集可比較）。資料極度不平衡、只在乎抓出稀有陽性（乳癌篩檢、詐欺偵測、瑕疵檢測）→ PR 更貼近真實代價。實務上常兩條都畫。
帶走 ROC 問「模型分得開嗎」；PR 問「在一百人才兩位病患的現實裡，每多抓一位真患者，要付出幾個誤警的代價」。低盛行率下，只有後者跟病人和門診負荷直接掛鉤。
第七節

一頁帶走

1. accuracy 的陷阱：在 2% 盛行率下，它被海量 TN 灌滿，漏診被藏起來。別用單一 accuracy 向主管報告模型好壞。

2. 混淆矩陣是地圖：真實（行）× 預測（列）的 2×2，所有指標都是在四格裡選格子、選方向相除。

3. 閾值是旋鈕：它決定你站在曲線「哪一點」，不改變曲線「形狀」。形狀由模型鑑別力決定。

4. ROC vs PR 的幾何：ROC 取兩條直行的命中率（必含 TN）；PR 取一行配一列（繞開 TN）。這就是 PR 在低盛行率下不被稀釋的原因。

5. 基準線會說話：ROC 的及格線是固定對角線；PR 的及格線 = 盛行率，會隨任務難度下沉，更誠實。

給主管的一句話 「在 2% 盛行率下，accuracy 只是把 98 個健康人猜對的獎勵。要決定模型能不能上線，請看混淆矩陣與 PR 曲線——它們才回答得了『我們每漏一位患者、或每誤警一位健康人，分別付出什麼代價』。」

混淆矩陣是地圖，閾值是你的腳步，
ROC 與 PR 是同一段路的兩種測量。
