02
TWO GAPS · 產業現實

兩個重要認知,撐起了這個班。

認知1 · 重中之重

有「用」,才是價值。

企業要的不只是「會寫 Python 的人」,而是站在現場、把痛點翻譯成資料問題、再用 AI/BI 工具落地的人 — 也就是「能用、有用」的人才。

  • 純技術人才看不懂現場 KPI
  • 純現場人才不會做資料 / AI
  • 中間斷層才是真正關鍵
認知2

AI 人才 ≠ 流通營運人才。

目前 AI 人才對物流與流通營運現場不熟悉,有技術卻難以融入現場 — 240 小時正是廠商 × 學員相互了解的好時機。

  • 流通服務業(物流倉儲 / 批發零售 / 電商與全通路)+ 企業物流
  • 支援性產業(流通資服業 / 物流設備 / 顧問業)
  • 非資訊背景學員 → 職涯廣度 > 資訊相關科系

若符合資格,歡迎繼續進一步探索下去…

  • 學歷大專校院副學士（含二專、五專）以上
  • 年齡年滿 18 歲至 35 歲（含）
  • 身分待業者 或 應屆畢業生(不得為全職在職勞工、自營作業者或公司負責人)

註 1. 不限科系背景。資訊科系對課程熟悉度高;然非資訊背景的跨域學習者,在就業上反而更具優勢。

註 2. 本班主要目標就業職務,為流通服務業(物流 / 倉儲 / 批發 / 零售 / 電商 / 連鎖通路)與企業物流部門之「智慧營運優化工程師」。

01
BEFORE YOU START · 四個問題

決定你適不適合走進這間教室。

這個課程不是為了讓你「再多一張結訓證書」,而是為了讓你在面試桌前,能不慌不忙地說:「應用智慧科技進行優化,我會做。」

Q1

你是否曾經感覺,空有學歷卻說不出自己會什麼?

履歷寫得再漂亮,自己心裡最清楚有沒有底。如果這句話戳到你了,請繼續看下去。

Q2

你願意承認自己是「小白」,但不願意一直當小白嗎?

我們接受 AI 零基礎、物流與營運零經驗的你進來,但前提是:你願意動手、願意問問題、願意被磨。

Q3

你能不能在 6 週 × 2 階段裡,為「你自己」負一次完整的責任?

沒有缺課的藉口,沒有「下次再交」的彈性。這 240 小時是你給自己的承諾。

Q4

你想要的是一張證書,還是一次「我會了」的扎實感?

政府的 5 萬獎勵金、廠商高於原職的起薪,都是結果。帶得走的,是你在 Demo Day 簡報時手不抖的那個自己。

02
WHO SHOULD APPLY · 誰適合

說在前面:不是每個人都適合進這間教室。

我們希望你誠實地對照下面兩欄。能在「適合」這欄打 4 個勾以上的人,會是這個課程最歡迎、也走得最遠的學員。

✓ 我們在等的你

  • 剛畢業／待業中,覺得自己「該會點什麼了」
  • 雖完全沒有基礎,但對 AI、資料、物流與營運優化很好奇且想學
  • 願意每天 08:30–17:30 投入兩階段共 6 週,出席率 ≥ 90%
  • 不害怕被問問題,不害怕回答「我還不會」
  • 願意跟組員一起把事情做出來,而不是各做各的
  • 把「政府補助」當作鼓勵,而不是動機本身

✕ 請先想清楚

  • 只是想領獎勵金、不想真的投入
  • 期待「短時間變專家」、不接受被磨
  • 無法配合 6 週每天 8 小時的時間承諾
  • 習慣自己單打獨鬥、不願組內協作
  • 把錯誤歸咎於環境而非自己的學習選擇
  • 已有穩定工作只想兼著上課

05
FAQ · 常見問題

來不及問的,先在這裡看完。

我不是資訊／物流／管理科系背景,可以報名嗎?

可以。本班不限科系、不限工作經驗。我們挑的是「想學的心 + 願意行動」。非資訊背景反而是優勢 — 你能站在現場、把痛點翻譯成資料問題,正是「智慧營運優化工程師」最值錢的地方。

需要會 Python 或 AI 嗎?

不需要。課程從零開始,先用 GenAI 構想、再用 Orange3 視覺化、最後才進 VS Code + Claude Code 寫 Python。AI 是方法,不是門檻。

5 萬獎勵金怎麼領?有條件嗎?

有,分兩階段核發:第一階段出席率 ≥ 90% 且後測 ≥ 80 分 → 2 萬;第二階段出席率 ≥ 90% 且完成成果發表並通過 → 3 萬,合計最高 5 萬。中途退訓(非不可歸責因素)須繳回已領獎勵金;應屆畢業生須取得畢業證書後方可領取。

媒合成功,高於原職平均月薪是保證的嗎?

不是保證,是合作廠商給的薪資建議。媒合需經面試與雙方意願,並非每位學員都能媒合成功 — 目標媒合率 ≥ 75%。

上課地點在哪?中部班和北部班有什麼不同?

中部班:國立臺中科技大學(臺中市北區三民路三段 129 號),116/6/28–8/13。北部班:龍華科技大學(桃園市龜山區萬壽路一段 300 號),116/7/19–9/3。兩班課程內容相同、排課日期不同,可依居住地區選擇。交通與住宿自理。

報名後就可以先上課嗎?

可以先「暖身」。完成線上報名即開通兩門課前線上課程:「解鎖 AI 時代的 0 到 1」與「流通營運的核心:AI 賦能倉儲與運輸管理」。開通帳號不代表錄取,錄取依甄選結果另行通知;課前課程為自主學習,不計入 240 小時。

說明會一定要參加才能報名嗎?

不一定,但強烈建議參加。說明會會揭露 4W、課程方法論、媒合機制細節,並能現場 Q&A — 報名前先參加,你會更清楚自己適不適合。
